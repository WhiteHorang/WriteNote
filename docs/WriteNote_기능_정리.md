# WriteNote 기능 정리

작성일: 2026-11-12 · 버전 1.0 · C# Windows Forms (.NET Framework 4.7.2)

WriteNote는 집중해서 글을 쓰기 위한 RTF 기반 글쓰기 프로그램이다. 이 문서는 지금 프로그램에서 **할 수 있는 일**과 **구현된 내용**을 정리한 것이다.

---

## 1. 글쓰기 화면

| 기능 | 설명 |
|---|---|
| 제목 + 본문 | 위쪽에 제목 입력칸, 아래쪽에 본문(RichTextBox) |
| 상단 버튼 | 새 문서 / 열기 / 저장 / 다른 이름으로 저장 |
| 상태 표시줄 | 글자 수(공백 포함/제외 선택), 저장 상태(새 문서 · 수정됨 · 저장됨 · 자동 저장됨 HH:mm) |
| 사이드 패널 | ☰ 버튼 또는 `Ctrl + B`로 열기/닫기 |
| 테마 | 어두운 테마(기본) / 밝은 테마. 메인 화면, 사이드 패널, 설정 창, 우클릭 메뉴까지 프로그램 전체에 적용 |
| 글꼴 | 본문 글꼴(설치된 글꼴 중 선택), 본문·제목 글자 크기(8~40) |
| 아이콘 | 보라색 바탕에 종이와 연필. exe 파일(탐색기), 창 제목 표시줄, 작업 표시줄, 작업 관리자, 모든 대화 상자에 같은 아이콘 |

## 2. 문서 저장 · 불러오기

| 기능 | 설명 |
|---|---|
| 새 문서 | `Ctrl + N`. 저장하지 않은 내용이 있으면 먼저 묻는다 |
| 저장 | `Ctrl + S`. 처음 저장할 때는 저장 위치를 고른다(문서 폴더 또는 지금 고른 폴더에서 시작) |
| 다른 이름으로 저장 | `Ctrl + Shift + S` |
| 열기 | `Ctrl + O`, 또는 문서 카드 더블클릭 |
| 파일 형식 | 본문은 `.rtf`, 제목·즐겨찾기·만든 날짜 등은 같은 이름의 `.json`에 따로 저장 |
| 자동 저장 | 1·3·5·10·30분마다. 한 번 이상 저장한 문서만. 확인 창이 떠 있는 동안에는 저장하지 않음 |
| 닫기 확인 | 저장하지 않은 내용이 있으면 새 문서·열기·창 닫기 전에 저장할지 묻는다(예 / 아니요 / 취소) |
| 안전 장치 | 읽을 수 없는 파일을 열려고 하면 지금 문서를 그대로 둔다. 정보 파일(JSON)이 깨진 문서는 파일 이름을 제목으로 해서 연다 |

## 3. 문서 관리 (사이드 패널)

### 문서 목록
- **전체 문서 / 최근 문서 / 즐겨찾기 / 휴지통** 분류 버튼
- 검색: 제목으로 찾기
- 정렬: 최근 수정순 / 오래된 수정순 / 이름순
- 문서 카드: 제목(즐겨찾기는 ★ 표시), 수정 날짜(오늘·어제·날짜), 하위 폴더에 있는 문서는 폴더 이름도 표시

### 폴더별 분류 (실제 하위 폴더)
- 폴더 선택 상자: **모든 폴더 / 분류 없음 / 각 폴더**. '전체 문서'와 '즐겨찾기'에서 사용할 수 있다
- `⋯` 메뉴: 새 폴더 만들기 / 폴더 이름 바꾸기 / 폴더 삭제 / 탐색기에서 열기
- 폴더 이름을 바꾸면 최근 문서, 열린 문서, 휴지통 복원 위치의 경로도 함께 바뀐다
- 폴더를 삭제하면 안의 문서는 휴지통으로 옮기고, 빈 폴더만 지운다
- 폴더를 고른 상태에서 새 문서를 저장하면 저장 창이 그 폴더에서 열린다

### 문서 카드 우클릭 메뉴
| 메뉴 | 설명 |
|---|---|
| 문서 열기 | 문서를 연다 |
| 즐겨찾기에 추가 / 해제 | ★ 표시 |
| 파일 위치 열기 | 탐색기에서 파일을 선택한 상태로 연다 |
| 이름 변경 | 파일 이름과 제목을 함께 바꾼다 |
| 폴더로 이동 | 분류 없음 / 각 폴더 / 새 폴더 만들어 이동. 같은 이름이 있으면 덮어쓰지 않는다 |
| 최근 목록에서 제거 | 파일은 그대로 두고 최근 목록에서만 뺀다 |
| 휴지통으로 이동 | 바로 지우지 않고 휴지통으로 옮긴다 |
| 속성 보기 | 제목, 위치, 크기, 만든·수정 날짜, 즐겨찾기 여부, 글자 수(공백 포함/제외) |

### 휴지통
- 삭제한 문서는 `%AppData%\WriteNote\Trash`에 보관한다. 문서 폴더를 바꿔도 휴지통은 그대로다
- 휴지통 카드: 삭제한 날짜 표시. 더블클릭하면 복원할지 묻는다
- 우클릭: **복원 / 영구 삭제 / 휴지통 비우기**. 영구 삭제와 비우기는 '예'를 눌러야만 실행된다
- 복원하면 원래 위치로 돌아가고, 제목과 즐겨찾기 정보도 그대로 유지된다. 같은 이름이 있으면 `제목 (2)`로 복원한다

## 4. 글쓰기 편의 기능

### 글쓰기 단축키 (설정에서 수정·삭제·추가 가능)
| 기본 단축키 | 입력되는 내용 |
|---|---|
| `Ctrl + Enter` | 세 줄 띄우기 |
| `Ctrl + Shift + .` | 구분선 `*   *   *` |
| `Ctrl + .` | 말줄임표 `⋯` |
| `Ctrl + [` | 겹낫표 `「」` (커서는 괄호 안) |
| `Ctrl + '` | 큰따옴표 `""` (커서는 따옴표 안) |
| `Ctrl + Shift + '` | 작은따옴표 `''` (커서는 따옴표 안) |

- 사용자 단축키: 이름, 키 조합(Ctrl·Alt·Shift + 키, F1~F12), 입력할 내용(여러 줄 가능)
- 키 조합이 정확히 같을 때만 실행된다(`Ctrl + .`과 `Ctrl + Shift + .`은 서로 다른 단축키)
- 중복 검사: 기본 단축키나 다른 글쓰기 단축키와 겹치면 저장할 수 없다
- 한글을 조합하는 중에 단축키를 누르면 조합 중인 글자를 먼저 확정한다

### 변경할 수 없는 기본 단축키
`Ctrl + S` 저장 · `Ctrl + Shift + S` 다른 이름으로 저장 · `Ctrl + O` 열기 · `Ctrl + N` 새 문서 · `Ctrl + B` 사이드 패널 · `Ctrl + F` 검색 · `F1` 설명서 · `Ctrl + C/X/V/Z/Y/A` 편집

### 문서 내 검색
- `Ctrl + F`로 검색 패널 열기
- `Enter` 다음 찾기 / `Shift + Enter` 이전 찾기 / `Esc` 닫기

### 붙여넣기
- **서식 빼고 글자만 넣기**(옵션): 웹이나 워드에서 복사한 글을 본문 글꼴·색으로 붙여 넣는다
- 옵션을 꺼도 붙여 넣은 글자의 색은 테마 색으로 맞춘다(어두운 화면에서 검은 글씨가 안 보이는 문제 방지)

### 맞춤법 검사
- 글을 쓰다 잠깐 멈추면, 틀린 것으로 의심되는 단어 아래에 **빨간 물결선**을 그린다(화면에만 그리고 문서에는 저장하지 않음)
- 우클릭: **추천 단어**(최대 5개, 띄어쓰기를 바꾸는 추천은 '(띄어쓰기)'로 표시) / **사전에 추가**(다음 실행에도 유지, 조사가 붙어도 통과) / **무시**(프로그램을 끌 때까지)
- **사용자 사전 관리**: 설정 → 글쓰기 → '사용자 사전...'에서 추가한 단어를 보고, 새로 넣거나 지울 수 있다. '확인'을 누르면 본문 물결선에 바로 반영된다
- 영어, 숫자가 섞인 말은 표시하지 않는다. 입력 중인 단어는 1.5초 동안 멈추면 표시한다
- 한글을 조합하는 중에는 검사하지 않는다(조합이 끊기지 않도록)
- 사전: hunspell-dict-ko 0.7.94. 사전은 시작할 때 뒤에서 불러온다(약 1초)

## 5. 설정 창

| 페이지 | 설정 |
|---|---|
| 일반 | 시작할 때 화면(새 문서 / 마지막으로 작업한 문서), 시작할 때 사이드 패널 열기 |
| 단축키 | 글쓰기 단축키 목록, 추가 / 수정 / 삭제 |
| 글쓰기 | 자동 저장과 간격, 글자 수 기준, 붙여넣기 서식 제거, 글쓰기 단축키 사용, 맞춤법 검사, 사용자 사전 관리 |
| 저장 및 문서 | 문서 저장 폴더(찾아보기 / 기본 위치로 / 폴더 열기). 폴더를 바꾸면 기존 문서와 하위 폴더를 옮길지 묻는다 |
| 화면 및 테마 | 테마, 본문 글꼴, 본문 글자 크기, 제목 글자 크기, 미리보기 |
| 공통 버튼 | 저장 / 취소(Esc) / 기본값 복원(지금 보는 페이지만). 저장하지 않고 닫으려 하면 확인 |

설정을 저장하면 프로그램을 다시 켜지 않아도 바로 적용된다.

### 설명서
- 설정 창 왼쪽 메뉴의 **'설명서'**(화면 및 테마 아래), 또는 글쓰기 화면에서 **F1**로 연다
- 13개 장: 소개, 문서 쓰기와 저장, 사이드 패널과 문서 목록, 폴더별 분류, 휴지통, 글쓰기 단축키, 맞춤법 검사, 문서 내 검색과 붙여넣기, 설정, 데이터 저장 위치와 백업, 문제 해결, 프로그램 정보, 라이선스 전문
- 왼쪽 목차를 누르면 그 장으로 이동하고, 위쪽 찾기 칸으로 본문을 검색할 수 있다(Enter = 다음 찾기)

## 6. 데이터 저장 위치

| 데이터 | 위치 |
|---|---|
| 문서(.rtf + .json) | `내 문서\WriteNote` (설정에서 변경 가능), 하위 폴더 = 분류 |
| 설정 | `%AppData%\WriteNote\settings.json` |
| 글쓰기 단축키 | `%AppData%\WriteNote\shortcuts.json` |
| 최근 문서 목록 | `%AppData%\WriteNote\recent_documents.json` |
| 휴지통 | `%AppData%\WriteNote\Trash\` |
| 맞춤법 사용자 사전 | `%AppData%\WriteNote\user_dictionary.txt` |

- 설정·단축키 파일이 손상되면 `*.broken.json`으로 옮겨 두고 기본값으로 시작한다
- 저장은 임시 파일에 먼저 쓰고 바꿔 넣는 방식이라, 저장 도중에 문제가 생겨도 기존 파일이 깨지지 않는다

## 8. 테스트와 배포

- **자동 통합 테스트 111개 모두 통과** (사용자 사전 관리, 설명서 포함): 단축키, 글자 수, 붙여넣기, 저장·불러오기, 자동 저장, 테마, 글꼴, 문서 폴더·옮기기, 설정 유지, 설정 창, 단축키 입력, 닫기 확인, 휴지통, 폴더별 분류, 맞춤법, 아이콘
  - 테스트는 환경 변수 `WRITENOTE_DATA_DIR`로 지정한 임시 폴더만 쓰고, 실제 `%AppData%\WriteNote`는 건드리지 않는다(테스트 전후 비교로 확인)
  - 본문 입력 관련 기능은 실제 한글 입력기로 여러 타자 속도에서 확인했다
- **직접 확인할 항목**: `통합테스트_체크리스트.md` 4장
- **배포**: **`WriteNote.exe` 파일 하나**(약 15MB). DLL 6개, 맞춤법 사전, 라이선스 문서가 exe 안에 들어 있다(`EmbeddedAssemblies.cs`). `배포\WriteNote_1.0.zip`(약 1.4MB). Release 빌드, 경고 0개
  - 빈 폴더에 exe만 복사해서 실행·한글 입력·맞춤법 물결선까지 확인했다
  - 실행 조건: .NET Framework 4.7.2 이상(Windows 10/11 기본 포함)

## 9. 알려진 한계

- 맞춤법 검사는 단어 단위다. 문맥이 필요한 오류(되요/돼요, 바램/바람)는 잡지 못하고, 띄어쓰기는 일부만 잡는다
- 줄이 바뀌는 곳에 걸친 단어에는 물결선을 그리지 않는다
- 하위 폴더는 한 단계까지만 분류로 쓴다
- 굵게·기울임 같은 서식 도구는 없다(문서를 열거나 테마를 바꾸면 본문 전체를 설정 글꼴·색으로 맞춘다)
- 창 제목 표시줄과 스크롤바는 Windows가 그려서 테마를 따르지 않는다
