1. 프로젝트 기본 구조 및 디자인

[완료] 프로젝트 생성: C# Windows Forms 프로젝트
[완료] 개발 환경: .NET Framework 4.7.2 기반
[완료] 메인 화면: MainForm 기본 구성
[완료] 디자인: 어두운 집중형 글쓰기 디자인
[완료] 색상 체계: 배경, 패널, 버튼, 강조 색상 통일
[완료] 폰트: 맑은 고딕 적용
[완료] 사이드 패널: 기본 구조 및 열기/닫기
[완료] 설정 창: SettingsForm 5개 페이지(일반, 단축키, 글쓰기, 저장 및 문서, 화면 및 테마) 모두 동작
[추가] 밝은 테마: 프로그램 전체(메인, 사이드 패널, 설정 창, 메뉴) 테마 전환
[추가] 테마 관리: ThemeManager가 어두운 색 ↔ 밝은 색 대응표로 실행 중에 색을 바꿈

[완료] 본문 작성: RichTextBox 기반
[완료] 글자 수 표시 (공백 포함/제외 기준 선택, 천 단위 쉼표)
[완료] 문서 수정 감지
[완료] 새 문서 생성
[완료] RTF 파일 저장
[완료] 다른 이름으로 저장
[완료] RTF 파일 불러오기 (불러오기 실패 시 이전 문서를 덮어쓰던 위험 수정)
[완료] 수정된 문서의 저장 여부 확인
[추가] 프로그램을 닫을 때도 저장 여부 확인
[추가] 문서를 열 때 현재 설정의 글꼴·테마 글자색으로 표시

3. 문서 관리 기능

[완료] 프로그램 내부 문서 목록
[완료] 최근 문서 표시
[완료] 즐겨찾기 관리
[완료] JSON 메타데이터로 문서 정보 별도 관리
[완료] 폴더별 문서 분류: 문서 폴더 안의 실제 하위 폴더 사용(한 단계)
       - 폴더 선택(모든 폴더 / 분류 없음 / 각 폴더), 폴더 만들기·이름 바꾸기·삭제
       - 문서 카드 우클릭 '폴더로 이동', 폴더를 고른 상태에서 새 문서 저장 위치 = 그 폴더
[완료] 휴지통 및 삭제 문서 복구
       - 삭제 시 %AppData%\WriteNote\Trash로 이동, 복원·영구 삭제·휴지통 비우기
       - 원래 위치에 같은 이름이 있으면 '제목 (2)'로 복원
[추가] 문서 메뉴(이름 변경, 즐겨찾기, 삭제, 속성 등) 파일 오류 처리 - 오류가 나도 프로그램이 종료되지 않음

4. 글쓰기 편의 기능

[완료] 세 줄 띄우기: Ctrl + Enter (문서 중간에서 커서가 어긋나던 버그 수정)
[완료] 구분선 입력: Ctrl + Shift + .
[완료] 말줄임표 입력: Ctrl + .
[완료] 겹낫표 입력: Ctrl + [
[완료] 큰따옴표 입력: Ctrl + '
[완료] 작은따옴표 입력: Ctrl + Shift + '
       (위 6개는 이제 설정에서 수정·삭제 가능)
[완료] 문서 내 검색 패널
[완료] 맞춤법 검사: hunspell 한국어 사전(hunspell-dict-ko 0.7.94) + WeCantSpell.Hunspell
       - 단어 단위 철자 검사. 문맥이 필요한 오류(되요/돼요 등)와 일부 띄어쓰기는 잡지 못함
[완료] 맞춤법 오류에 빨간 밑줄 표시: 빨간 물결선(화면에만 그림, 문서에는 저장하지 않음)
       - 우클릭: 추천 단어 / 사전에 추가(조사가 붙어도 통과) / 무시
[추가] 맞춤법 사용자 사전 관리: 설정 > 글쓰기 > '사용자 사전...'에서 단어 보기·추가·삭제
[완료] 한글 조합 끊김 수정: 천천히 칠 때 '됐다'가 'ㄷㅙㅆ다'로 입력되던 문제 (직접 확인 완료)
[추가] 자동 저장 (1·3·5·10·30분, 한 번 이상 저장한 문서만)
[추가] 붙여넣기 서식 제거 옵션 (끈 상태에서도 글자색은 테마 색으로 맞춤)
[추가] 한글 조합 중 단축키를 누르면 조합 중인 글자를 먼저 확정 [확인 필요]

5. 키보드 단축키 관리

[완료] 기본 단축키: 저장, 열기, 새 문서 등 공통 기능
[완료] SettingsForm의 단축키 페이지
[완료] 단축키 목록 ListView 및 3개 열 구성
[완료] 추가·수정·삭제 버튼 생성 및 연결 (더블클릭·Enter로 수정, Delete로 삭제)
[완료] ShortcutEditForm 입력 창 구성 (프로젝트 파일에 빠져 있던 문제 해결)
[완료] Ctrl, Shift, Alt 및 일반 키 조합 인식
[완료] 사용자 지정 텍스트 입력 단축키 추가
[완료] 사용자 단축키 수정 및 삭제
[완료] 단축키 중복 검사 (기본 단축키 및 다른 글쓰기 단축키와 비교)
[완료] JSON 저장 및 불러오기 (%AppData%\WriteNote\shortcuts.json)
[완료] MainForm과 연동하여 실제 글쓰기 화면에서 실행 (설정 저장 즉시 반영)
[추가] 단축키 기본값 복원, 글쓰기 단축키 전체 켜기/끄기

단축키 관리 기준
- 기본 단축키(Ctrl + S, Ctrl + N, Ctrl + O 등)는 변경할 수 없으며 설정 목록에 표시하지 않는다. (적용됨)
- 글쓰기 관련 기본 단축키는 설정 목록에서 수정·삭제할 수 있도록 한다. (적용됨)
- 사용자가 직접 추가한 단축키는 추가·수정·삭제할 수 있도록 한다. (적용됨)

[추가] exe 하나로 배포: DLL 6개·맞춤법 사전·라이선스 문서를 exe 안에 넣고 실행할 때 꺼내 씀

현재 개발 위치

계획한 모든 기능 구현 완료. 처음 '추후 검토'·'미구현'이던 휴지통, 폴더별 분류,
맞춤법 검사까지 구현했다. 자동 통합 테스트 99개가 모두 통과하며, 최종 빌드와
배포 파일(WriteNote_1.0.zip)을 준비했다. 남은 일은 실제 키보드·마우스로 하는
직접 확인(통합테스트_체크리스트.md 4장)이다.

남은 일 및 알려진 한계

[확인 필요] 실제 키보드 입력: 한글 조합 중 단축키, 맞춤법 물결선 위치(스크롤·글꼴 크기 변경 시)
[확인 필요] 대화 상자: 폴더 선택 창, 폴더 이름 입력 창, 문서 옮기기 질문
[확인 필요] 시간이 필요한 기능: 자동 저장, 재실행 시 설정 유지
[한계] 맞춤법 검사는 단어 단위라 문맥이 필요한 오류는 잡지 못하고, 띄어쓰기는 일부만 잡는다.
[한계] 하위 폴더는 한 단계까지만 지원한다.
[한계] 창 제목 표시줄과 스크롤바는 Windows가 그려서 테마를 따르지 않는다.
[관리] 프로젝트 폴더가 git으로 관리되지 않으므로 별도 백업을 권장한다.

진행 시 참고

각 작업은 작은 단계로 나누어 진행한다. UI 구성이나 코드 변경 후에는 빌드
및 실제 동작을 확인하고 다음 단계로 넘어간다. 완료 상태는 실제 확인 후
갱신한다.
