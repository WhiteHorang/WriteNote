## 1. 자동 통합 테스트 결과: 50개 모두 통과

- 사용자 데이터 보호: 테스트 전에 `%AppData%\WriteNote`를 백업하고, 끝난 뒤 복원했다. 복원 후 원본과 파일 내용이 같은지 해시로 확인했다.
- 테스트 문서는 임시 폴더에서만 만들었다.

| 영역 | 확인한 내용 |
|---|---|
| 글쓰기 단축키 (7) | 기본 단축키 입력, 괄호 안 커서 위치, `Ctrl + .`과 `Ctrl + Shift + .` 구분, 문서 중간 `Ctrl + Enter` 뒤 커서 위치, 사용자 단축키가 기본 단축키보다 먼저 실행되는지, 여러 줄 내용 입력, 단축키 끄기 |

| 문서 폴더·목록 (2) | 설정한 폴더의 문서만 목록에 보이는지 |

| 설정 창 (4) | 저장된 값 표시, 열기만 했을 때는 '변경됨'이 아닌지, 바꾸면 '변경됨'이 되는지, Esc = 취소 |

| 닫기 (1) | 저장하지 않은 내용이 있으면 확인 창을 띄우고, '취소'를 고르면 닫지 않는지 |

## 2. 이번 단계에서 고친 문제

코드 검토와 테스트에서 찾은 문제다.

1. **문서 열기 실패 시 데이터 손실 위험**
   - 문제: 문서 정보(JSON)가 깨진 문서를 열면 화면에는 새 문서가 보이는데 파일 경로는 이전 문서로 남았다. 이 상태에서 저장하면 이전 문서 파일을 덮어썼다.
   - 수정: 임시로 먼저 읽어 보고, 성공했을 때만 화면과 파일 경로를 함께 바꾼다. JSON이 깨진 경우에는 파일 이름을 제목으로 쓴다.
2. **창을 닫을 때 저장 확인이 없음**
   - 수정: 저장하지 않은 내용이 있으면 '저장하시겠습니까?'를 묻는다.
3. **밝은 테마에서 단축키 입력 창의 입력칸이 검은 바탕 + 검은 글자**
   - 원인: Windows 기본 입력칸 색을 흰색으로 착각해 바꿨다.
   - 수정: 시스템 색은 바꾸지 않는다.
4. **테마를 바꾼 뒤 문서 카드에 마우스를 올리면 글자 부분만 색이 안 바뀜**
   - 수정: 부모 색을 물려받는 컨트롤은 칠하지 않는다.
5. **테마를 바꾼 뒤 Ctrl + Z를 누르면 이전 테마의 글자색이 되살아남**
   - 수정: 테마나 글꼴을 적용한 뒤 실행 취소 기록을 비운다.
6. **밝은 테마 설정 창에서 선택된 메뉴 글자가 보라 배경에 검은색**
   - 수정: 선택된 메뉴는 흰 글자로 표시한다.
7. **설정 창에서 Esc가 동작하지 않음**
   - 수정: Esc를 취소 버튼과 연결했다.
8. **문서 옮기기 중 문서 정보(JSON)만 옮기지 못하면 문서와 정보가 갈라짐**
   - 수정: 이 경우 문서도 원래 자리로 되돌린다.
9. **글꼴과 버튼 모양 영역(Region) 정리 누락**
   - 수정: 새로 바꿀 때 이전 것을 정리한다.

## 3. 8단계(마무리)에서 고친 문제

통합 테스트 때 남겨 둔 문제와 정리 중에 찾은 문제를 고쳤다. 자동 테스트는 4개를 더해 **54개 모두 통과**한다.

| 문제 | 수정 |
|---|---|
| 이름 바꾸기·즐겨찾기·삭제·속성·파일 위치 열기에 파일 오류 처리가 없음 | 오류가 나도 프로그램이 종료되지 않고 안내한다. 이름 바꾸기 중 정보 파일만 옮기지 못하면 문서 이름도 되돌린다. |
| 최근 문서 목록 파일이 깨지면 오류 | 빈 목록으로 시작한다. |
| 서식을 유지한 붙여넣기에서 검은 글씨가 안 보임 | 굵게 등의 서식은 유지하고 글자색만 테마 색으로 맞춘다. |
| 한글 조합 중 단축키 | 단축키 내용을 넣기 전에 조합 중인 글자를 먼저 확정한다. **직접 확인이 필요하다.** |
| 설정 저장 중 일부만 실패 | settings.json이 저장되었으면 창을 닫을 때 메인 화면이 설정을 다시 읽는다. |
| **제목만 바꾸면 '수정됨'이 되지 않음** (원래 있던 버그) | 제목 변경 처리기가 연결되어 있지 않았다. 연결해서 제목만 바꿔도 저장 확인을 받는다. |
| 문서 속성의 '공백 포함 글자 수'가 메인 화면과 다름 | 줄바꿈을 세지 않도록 맞췄다. |
| 정리 | 데이터 폴더 경로 중복 코드를 하나로 합쳤다. 쓰지 않는 코드를 지웠다. |

최종 빌드: `배포\WriteNote_1.0\` 폴더와 `배포\WriteNote_1.0.zip` (Release 빌드, 경고 0개)

## 4. 직접 확인할 항목

키보드 입력, 대화 상자, 실제 시간 경과, 프로그램 재시작이 필요해서 자동으로 확인하지 못한 항목이다.

### 단축키
- [ ] 설정 → 단축키 → 추가에서 `Ctrl + Alt + 1`을 눌러 입력되는지 (한글 입력 상태에서도)
- [ ] 기존과 겹치는 키(`Ctrl + .`)와 기본 단축키(`Ctrl + S`)가 저장되지 않는지
- [ ] 목록에서 더블클릭·Enter로 수정, Delete로 삭제 (삭제 전에 확인 창이 뜨는지)
- [ ] 한글을 조합하는 중(예: '가'를 치는 중)에 `Ctrl + [`를 누르면 '가'가 먼저 확정되고, 그 뒤에 `「」`가 들어가 커서가 괄호 안에 놓이는지
- [ ] 제목만 바꾸고 창을 닫으면 저장 확인이 뜨는지
- [ ] 문서 카드 우클릭 메뉴(이름 바꾸기, 즐겨찾기, 삭제, 속성)가 정상 동작하는지
- [ ] 저장 후 메인 화면에서 바로 동작하고, 프로그램을 다시 켜도 유지되는지

### 저장·문서
- [ ] 새 문서 `Ctrl + S` → 저장 위치 창이 설정한 문서 폴더에서 열리는지
- [ ] 설정 → 저장 및 문서 → 찾아보기로 새 폴더를 고르고 저장 → 옮기기 질문에 **예** → 문서·즐겨찾기 표시가 그대로인지
- [ ] '폴더 열기' 버튼으로 탐색기가 열리는지
- [ ] 수정한 뒤 창 닫기(X) → 확인 창에서 **예**는 저장 후 종료, **아니요**는 그냥 종료, **취소**는 계속 편집인지

### 휴지통 (추가 기능, 자동 테스트 8개 통과)
- [ ] 문서 카드 우클릭 → '휴지통으로 이동' → 목록에서 사라지고, 사이드 패널 아래 '휴지통'에 보이는지
- [ ] 휴지통 카드 더블클릭 → 복원 질문에 '예' → 원래 위치로 돌아오고 즐겨찾기 표시도 그대로인지
- [ ] 휴지통 카드 우클릭 → 영구 삭제 / 휴지통 비우기 → 확인 창에서 '예'를 눌러야만 지워지는지
- [ ] 열려 있는 문서를 휴지통으로 옮기면 새 문서 화면이 되는지 (수정 중이었다면 저장 여부를 먼저 묻는지)

### 폴더별 분류 (추가 기능, 자동 테스트 12개 통과)
- [ ] '⋯' → 새 폴더 만들기 → 이름 입력 → 폴더 선택 상자에 생기고 그 폴더가 선택되는지
- [ ] 폴더를 고른 상태에서 새 문서를 `Ctrl + S`로 저장하면 저장 창이 그 폴더에서 열리는지
- [ ] 문서 카드 우클릭 → '폴더로 이동' → 다른 폴더 선택 → 목록과 '모든 폴더' 보기의 폴더 이름 표시가 바뀌는지
- [ ] '⋯' → 폴더 이름 바꾸기 → 그 폴더의 문서를 최근 문서에서 열 수 있는지 (경로 갱신)
- [ ] '⋯' → 폴더 삭제 → '예' → 안의 문서가 휴지통에 들어가고, 복원하면 폴더가 다시 만들어지는지
- [ ] 이름 입력 창에서 이미 있는 이름이나 `/` 같은 문자를 넣으면 안내가 뜨는지

### 맞춤법 검사 (추가 기능, 자동 테스트 10개 통과)
- [ ] 본문에 `됬다`, `몇일`, `설겆이`를 입력하고 잠깐 멈추면 빨간 물결선이 생기는지 (입력 중인 단어에는 아직 안 생기는지)
- [ ] 물결선 단어를 우클릭 → 추천 단어를 고르면 바뀌는지, '사전에 추가' 후 다시 실행해도 표시되지 않는지
- [ ] 등장인물 이름을 '사전에 추가'하면 `민수가`, `민수에게`처럼 조사가 붙어도 표시되지 않는지
- [ ] 긴 문서를 스크롤할 때 물결선이 글자와 함께 움직이고 엉뚱한 곳에 남지 않는지
- [ ] 글꼴 크기를 바꾸거나 밝은 테마로 바꿨을 때 물결선 위치가 글자 아래에 맞는지
- [ ] 설정 → 글쓰기 → '맞춤법 검사' 끄면 물결선이 모두 사라지는지
- [ ] 설정 → 글쓰기 → '사용자 사전...' → 단어를 지우고 '확인' → 본문에서 그 단어에 다시 물결선이 생기는지
- [x] 한글을 천천히 칠 때 조합이 끊기지 않는지 (됐다 → ㄷㅙㅆ다 문제 수정, 직접 확인 완료)

### exe 하나 배포
- [x] 빈 폴더에 WriteNote.exe만 복사해서 실행, 한글 입력, 맞춤법 물결선 (확인 완료)
- [ ] 다른 컴퓨터(또는 다른 폴더)에 WriteNote.exe만 옮겨서 실행해 보기
- [ ] 설명서 13장(라이선스 전문)이 보이는지

### 설명서 (추가 기능, 자동 테스트 7개 통과, F1은 실제 실행에서 확인)
- [ ] 설정 창 왼쪽 메뉴 '화면 및 테마' 아래 '설명서'를 누르면 설명서 창이 열리는지
- [ ] 목차를 누르면 그 장으로 이동하는지, 찾기 칸에 단어를 넣고 Enter를 누르면 찾아지는지
- [ ] 창 크기를 늘리고 줄여도 목차·본문이 잘 맞는지, 밝은 테마에서도 잘 읽히는지

### 글쓰기
- [ ] 자동 저장 1분으로 설정 → 저장한 적 있는 문서를 수정하고 1분 이상 기다리면 상태 표시줄에 '자동 저장됨 HH:mm'이 나오는지
- [ ] '저장하시겠습니까?' 창을 띄워 둔 채 1분을 기다려도 자동 저장되지 않는지
- [ ] 웹 페이지 글을 붙여 넣었을 때 서식 제거 켜기/끄기에 따라 결과가 달라지는지

### 화면
- [ ] 밝은 테마로 저장 → 메인, 사이드 패널, 우클릭 메뉴, 설정 창, 단축키 입력 창이 모두 읽기 좋은지
- [ ] 테마를 바꾼 뒤 문서 카드에 마우스를 올리거나 클릭할 때 색이 자연스러운지
- [ ] 본문 글꼴을 바꾸면 열린 문서에 바로 적용되는지

### 시작
- [ ] '마지막으로 작업한 문서 열기' + '사이드 패널 열기'를 켜고 다시 실행하면 그대로 적용되는지
